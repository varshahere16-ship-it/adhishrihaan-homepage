# Adhishrihaan Foundation — Bootstrap Replica

Bootstrap 5 recreation of the Adhishrihaan Foundation homepage, rebuilt from the supplied live-page source and current homepage structure.

## Run
Open `index.html` through localhost (XAMPP/VS Code Live Server).

## Notes
- Uses Bootstrap 5.
- Uses the site's public image URLs so the replica can match the live imagery without bundling copyrighted site assets.
- Desktop header/hero overlap, typography, buttons, focus cards, grant gallery, blog state, events carousel, footer and responsive behavior are recreated in custom CSS.
